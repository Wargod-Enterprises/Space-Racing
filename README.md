# Space Racing

A 3D racing game set in 2060: riders on metamaterial boards lock onto Earth's magnetic field lines and race loops around the planet, jumping between lanes and braving the tight, fast polar hairpins.

Built in **Godot 4.7.2**.

- [Space Racing.txt](Space%20Racing.txt): the prototype build spec (foundational design document)

## Playing the prototype

1. Open Godot 4.7.2, click **Import**, and pick `project.godot` in this folder.
2. Press **F5**.

Tuning numbers live in `scripts/tuning.gd`.
